# Інформаційна система супроводу кваліфікаційних робіт 🎓

Цей репозиторій містить вихідний код вебзастосунку для автоматизації процесів підготовки, рецензування та захисту кваліфікаційних (курсових та дипломних) робіт. Проєкт розроблено як практичну частину дипломної роботи з фокусом на комплексну інформаційну безпеку, управління доступом та криптографічний захист документів.

## Основні можливості системи

- **Рольова модель доступу (RBAC):** Чітке розмежування повноважень між Студентами (авторами), Викладачами (керівниками, рецензентами, членами комісії) та представниками Деканату (організаторами).
- **Управління життєвим циклом:** Автоматизований перехід роботи між станами: *подання теми → затвердження → виконання → рецензування → допуск → захист*.
- **Робота з PDF-документами:** Завантаження версій роботи, клієнтська перевірка формату (MIME-тип, сигнатура `%PDF-`), збереження історії правок.
- **Комплексна безпека та RLS:** Використання політик Row Level Security (RLS) у PostgreSQL для суворого контролю доступу до даних на рівні рядків. Авторизація прив'язана не лише до ролі, а й до статусу конкретної роботи.
- **Захищений гостьовий доступ:** 
  - Публічний перегляд каталогу успішно захищених робіт.
  - Завантаження копії документа з **динамічним водяним знаком**.
  - Контроль гостьових сеансів за допомогою власного механізму токенів (HMAC-SHA-256) із часовим обмеженням (24 години).

## Стек технологій

**Клієнтська частина (Frontend):**
- **Ядро:** React (TypeScript), Vite
- **Робота з PDF:** `PDF.js` (рендеринг сторінок), `jsPDF` (клієнтська збірка документів)

**Серверна частина (Backend - Supabase):**
- **База даних:** PostgreSQL (із застосуванням RLS та міграцій)
- **Автентифікація:** Supabase Auth (вкл. підтвердження Email)
- **Сховище:** Supabase Storage (приватні бакети для PDF)
- **API та Логіка:** Supabase Data API, RPC (Remote Procedure Calls)
- **Серверні функції:** Edge Functions (Deno, `pdf-lib` для маркування документів та перевірки токенів)

### Попередні вимоги

Для локального запуску вам знадобиться встановлений [Node.js](https://nodejs.org/) (рекомендовано версію 18+) та налаштований проєкт у [Supabase](https://supabase.com/).

### Налаштування середовища

Створіть файл `.env` у кореневій теці проєкту та додайте ваші ключі:
```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_EMAIL_CONFIRM_REDIRECT_TO=http://localhost:5173/login
```

### Запуск 

### `npm install`
Встановлює всі залежності, вказані у файлі `package.json`.\
Ця команда гарантує, що всі необхідні пакети завантажені та доступні для правильної роботи проєкту.

### `npm run dev`
Запускає застосунок у режимі розробки.\
Відкрийте [http://localhost:5173](http://localhost:5173), щоб переглянути його у браузері.

### `npm run build`
Створює готову збірку застосунку для продакшену в папку `dist` (або `build`).\
Команда коректно пакує React у режимі продакшену та максимально оптимізує файли для найкращої продуктивності.

### `npm run preview`
Запускає локальний вебсервер для попереднього перегляду готової продакшен-збірки.\
Ця команда дозволяє локально перевірити, як працюватиме застосунок після розгортання на сервері (виконується після `npm run build`).
